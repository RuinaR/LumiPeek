# LumiPeek — 꼬미가 내 사진을 구경해요!

> **P0 감사 / P1 순수 모듈 구현 중**: 설치 가능한 플러그인이 아닙니다. 실제 SDK 통합과 화면 연출, Steam 창작마당 배포는 아직 검증되지 않았습니다.

LumiPeek은 [Little LUMI Model](https://store.steampowered.com/app/5075020/)용 사진 감상 확장 플러그인입니다. 사용자가 **직접 허용한 사진 폴더**에서 이미지를 한 장 선택해, 로컬 비전 AI가 장면을 이해하고 꼬미가 **작은 사진 미리보기와 짧고 자연스러운 감상**을 보여줍니다.

## 핵심 원칙

- **원래 꼬미의 모든 기능을 그대로 유지**합니다. 기존 대화·음성·호감도·행동·다른 모드·집중/전체화면 기능은 변경하지 않습니다.
- 사진 감상은 완전히 선택적인 추가 기능입니다. AI가 없거나 분석이 실패해도 기본 꼬미는 계속 정상 작동합니다.
- 말풍선은 SDK의 문자열 API로 출력합니다. 현재 공식 SDK 1.5.1에는 말풍선 내부 이미지 삽입 API가 확인되지 않아, 사진은 **별도 작은 미리보기 창**으로 꼬미 옆에 표시하는 것을 목표로 합니다.
- 허용한 폴더의 이미지 파일만 **읽기 전용**으로 분석하고 원본 파일은 절대 수정·이동·삭제하지 않습니다.
- 화면 캡처, 게임 프로세스 접근, 전역 입력 감시는 사용하지 않습니다.

## 현재 구현과 검증

- Java 처리 모듈과 Windows x64 JNI 파일 접근 모듈을 구현했습니다. PNG/JPEG 헤더·크기·픽셀 검사, 최대 1024픽셀 PNG 재인코딩, 세션 한정 중복 식별, 분석 작업 1개 제한, 취소·타임아웃, JSON 응답 검사를 제공합니다. SDK·Ollama와는 아직 연결하지 않았습니다.
- 원본 최대 25 MiB, 30 MP. 메모리에서 새 이미지로 만들어 메타데이터를 전달하지 않습니다. WebP/GIF/BMP는 현재 거부합니다.
- 실패 진단은 코드만 사용합니다. 경로·사진·모델 원문을 로그에 기록하거나 분석 결과를 저장하는 기능은 없습니다.
- **Windows 로컬 NTFS 폴더 읽기 검증**: 표준 Java `fileKey()` 대신 열린 핸들의 볼륨·파일 ID를 사용합니다. 부모 핸들에 상대적으로 한 구성요소씩 열고 같은 파일 핸들에서 검사·읽기를 수행합니다. 합성 폴더에서 루트·디렉터리·파일 교체, 권한 거부, 사용 중인 파일, 탐색 중 삭제·교체를 검증했습니다.
- 고정 로컬 NTFS만 허용합니다. 링크·정션·재분석 지점·다중 하드링크·클라우드 오프라인/회수 대상·UNC·네트워크 및 SUBST 경로는 거부합니다. DLL이 초기화되지 않았거나 검증에 실패하면 읽지 않습니다. 원본에는 쓰기 권한을 요청하지 않습니다. 읽는 동안 대상 파일의 쓰기·이름 변경, 열린 디렉터리의 이름 변경은 잠시 제한됩니다.
- 실제 OneDrive/SMB 환경, 악의적인 커널·필터 드라이버, SDK 패키지 로딩은 **NOT VERIFIED**입니다. 이는 승인된 코드 내부의 읽기 정책이며 OS 보안 샌드박스나 전체 배포 안전성 인증이 아닙니다.
- 파일 접근과 디코딩의 시간 제한·취소는 처리 단계 사이에서 확인합니다. 커널 호출이나 멈춘 디코더를 강제 종료하지 못하므로 작업이 실제 종료될 때까지 새 분석을 거부하며 늦은 결과는 폐기합니다. 강제 시간·자원 격리는 미구현입니다.
- 응답 검사는 형식·길이·일부 위험 표현을 제한하지만 프롬프트 인젝션이나 콘텐츠 안전성을 보장하지 않습니다. `safeToShow`는 모델의 주장일 뿐 독립적인 콘텐츠 판정이 아닙니다.
- 기존 꼬미 코드를 변경하거나 SDK 진입점을 등록하지 않았습니다. 기존 모드와의 실앱 호환성은 **NOT VERIFIED**입니다.

Java 검사에는 설치된 JDK 17 이상과 PowerShell을 사용합니다. Windows 경계 검사에는 x64 MSVC Build Tools와 Windows SDK도 필요합니다. 외부 의존성을 내려받거나 앱·모델을 실행하지 않습니다.

```powershell
./scripts/test.ps1 -JdkHome '설치된 JDK 경로'
./scripts/test.ps1 -JdkHome '설치된 JDK 경로' -WindowsBoundary
./scripts/build-native.ps1 -JdkHome '설치된 JDK 경로' -Analyze
./scripts/audit.ps1
```

검사는 합성 이미지와 `build/` 임시 폴더만 사용하며 headless로 실행합니다. 네이티브 구성요소가 없는 기본 검사는 읽기 거부를 확인합니다. `-WindowsBoundary`는 배포용 DLL로 회귀 검사하고, 별도 테스트 DLL로 경쟁 조건을 검증합니다. 테스트 전용 함수는 배포용 DLL에서 제외하고 DLL·빌드 산출물은 Git에 넣지 않습니다. 다른 MSVC 설치 위치는 `build-native.ps1 -VcVars`로 지정할 수 있습니다.

실제 SDK 1.5.1 통합에는 [공식 배포 정보](https://github.com/studio-lumi-h/little-lumi-sdk/blob/main/sdk.json)의 JDK 25가 필요합니다. [SDK 문서](https://github.com/studio-lumi-h/little-lumi-sdk/blob/main/docs/API.md#lifecycle)는 모드 루트 `native/`의 Windows x64 DLL과 보호된 실행 사본을 지원합니다. 해당 실행 사본에서 DLL을 로드하는 통합과 코드 동의·변경 후 재동의는 배포 전에 검증해야 합니다. 현재는 설치 가능한 모드 패키지를 제공하지 않습니다.

## 사용자 경험 (목표)

1. Steam 창작마당에서 LumiPeek을 구독하고 꼬미의 플러그인 동의를 거쳐 활성화합니다.
2. 설정에서 로컬 Ollama 연결 상태를 확인하고 비전 모델을 고릅니다. Ollama가 없으면 설치 방법을 안내합니다.
3. 모델을 다운로드해야 한다면 **출처·용량·라이선스·대상 서버 확인 후 사용자가 동의**하면 진행률을 표시하며 자동 다운로드합니다.
4. 사진 폴더를 하나 이상 지정하고 하위 폴더 포함·자동 탐색 빈도를 설정합니다.
5. 꼬미가 사진 한 장을 고르면 안전하게 축소한 사진과 `···`를 먼저 보여주고 백그라운드 AI가 분석하는 흐름을 계획합니다. 사진은 머리에 붙이지 않고 조금 떨어져 자체 창만 부드럽게 따라오며, 캐릭터의 이동·시선·행동은 바꾸지 않습니다.
6. 분석이 끝나면 같은 사진을 유지하며 감상으로 전환합니다. 조용한 상태나 기존 대화가 우선이며, 실패·취소·대상 소멸·종료 시 자체 미리보기를 정리합니다. 사용자는 언제든 일시정지·닫기·폴더 제거·기록 삭제를 할 수 있습니다.

분석 중 연출은 **P1 안전 작업 이후 P3/P4에서 구현할 예정**입니다. SDK `showBusyFor()`는 사진당 한 번만 사용하고 최대90초 뒤에는 자체 미리보기의 `···`만 유지하는 정책입니다. [공식 SDK](https://github.com/studio-lumi-h/little-lumi-sdk/blob/main/docs/API.md)는 busy 소유권 토큰을 제공하지 않아, 다른 대화를 덮지 않는 즉시 감상 전환·취소 시 조기 해제는 미확정입니다. 포커스·클릭 통과·다중 모니터/DPI도 아직 검증되지 않았으며 현재 동작하는 UI 기능은 아닙니다.

## AI 모델 (초기 후보)

- 로컬 Ollama를 기본 지원합니다. **하나의 비전-언어 모델이 사진 이해와 감상 생성**을 수행합니다.
- 기본 후보: [Qwen3-VL 4B Instruct](https://ollama.com/library/qwen3-vl:4b-instruct). 2B 및 8B 선택 가능성을 지원하되 **실제 태그·라이선스·크기·성능은 구현 전 확인**합니다.
- 모델은 Steam 모드 패키지에 포함하지 않습니다. 사용자 승인 없이 Ollama/모델을 설치하거나 실행하지 않습니다.
- 기본 요청 대상은 사용자가 명시적으로 설정한 로컬 Ollama 루프백 주소입니다. 임의 외부 URL이나 이미지 전송은 허용하지 않습니다.

## 이미지 지원 및 개인 정보

- 일반 사진·동물·풍경·게임 화면·일러스트·만화·밈 등 지원을 목표로 합니다. 실제 디코더가 지원하는 JPG/PNG/WebP/GIF 등 형식과 한계는 개발 중 검증합니다. GIF는 첫 프레임 등 명확한 정책을 적용합니다.
- 합법적인 성인 이미지는 로컬 비전 모델의 입력 대상이 될 수 있지만, 모델이 언제나 묘사하거나 반응할 수 있다는 보장은 없습니다. 별도 명시적 동의, 자동 미리보기 기본 비활성, 부적절한 노출 방지 기능을 둡니다.
- Steam 공개판의 성인 콘텐츠 AI 반응 기능은 **보류**합니다. [SDK 이용 조건](https://github.com/studio-lumi-h/little-lumi-sdk/blob/main/LICENSE-SDK.txt)은 별도 허락 없는 루미의 성적 표현을 제한합니다. [Steamworks 안내](https://partner.steamgames.com/doc/gettingstarted/contentsurvey?l=english)는 실시간 생성 성인 성적 콘텐츠를 허용하지 않는다고 설명하며, 이 플러그인의 Workshop 적용 범위와 제작자 승인은 미확정입니다. 미성년자의 성적 콘텐츠나 기타 불법 자료는 지원하지 않습니다.
- 파일명·폴더 경로·원본 사진·프롬프트·AI 원문을 원격으로 전송하거나 공개 로그에 남기지 않습니다. 등록 폴더 외부로 이어지는 링크/정션을 따라가지 않습니다.

## 다른 프로그램과의 공존

- 메이플스토리 및 다른 외부 프로그램의 프로세스·메모리·화면·입력에 접근하지 않습니다.
- 다른 프로그램의 키보드·마우스 조작, DLL 주입, 후킹, 매크로를 사용하지 않습니다.
- SDK의 `quietNow()`가 참이면 사진 감상 출력은 보류합니다. 다른 말풍선이 보이면 절대 가로채지 않고 이번 반응을 미룹니다/생략합니다.
- **제재 위험 0%를 보장하는 것은 아닙니다.** 비침습적인 구현과 사용자 제어를 우선합니다.
